# Changelog

## 0.3.8-alpha.3 - 2026-10-20

- Default cookieless YouTube playback using a pinned private PO Token service; explicit optional account-cookie mode.
- Per-bot extensions, command switches and aliases, and independently configurable TR/EN TTS.
- Expanded Turkish translations, player-widget controls, and clearer media and permission diagnostics.
- Automatic radio presets, bot track cover/description support, and improved connection and voice-port setup.
- Server selection, privilege-key tools, widget usability and encrypted logical snapshot improvements.
- Added targeted API, media, browser and native amd64/ARM64 provider checks; updated deployment guides.
- Preserves existing settings, accounts, server data and music volumes when updating the Manager.

## 0.3.8-alpha.2 - 2026-10-18

- Original accent-aware waveform logo, favicon and installable application icons.
- Widget, permissions and bot UI translations; persistent TR/EN selection.
- HTTP-compatible privilege-key copy with accurate failure feedback.
- Automatic bot voice-port discovery and stop/start socket-race fix.
- Visible bot endpoint, client identity and connection errors.
- Optional local Piper TR/EN TTS, configurable `!say`, bounded input and cooldowns.
- Installer TTS package option, safer access summaries and optional voice UID grant.
- Updated panel documentation; amd64/ARM64 optional-engine CI smoke tests.

## 0.3.8-alpha.1 - 2026-10-18

Alpha preview. The application has not reached its first stable release.

- Persistent TR/EN language selection and refreshed panel appearance.
- Terminal-based first administrator setup with a staged bcrypt hash.
- Automatic TS3/TS6 registration in either installation order.
- Multiple connections and separate bots, preserving existing settings on synchronization.
- Private network linking for the default primary and secondary stacks.
- Signed platform-specific archives and installation regression checks.
